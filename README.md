# python-beginner-tutor

一个面向 Python 零基础自学者的 Codex 技能：帮你识错、记错题、讲口诀。

## 功能
- 识别常见新手错误（漏括号、赋值 vs 调用、缩进、中英文标点等）
- 按固定模板把错题追加进你的错题本
- 用口诀和类比讲解函数与语法（函数 = 榨汁机）

## 安装
把本文件夹复制到 Codex 技能目录：

```bash
cp -R . ~/.codex/skills/python-beginner-tutor
```

装好后新开一个对话，贴代码或报错截图即可触发。

## 目录
- `SKILL.md`：技能说明与工作流程
- `references/错误类型速查.md`：常见报错排查表
- `references/函数速记卡.md`：新手必背函数与记忆口诀

## 提示
错题本默认生成在技能同目录的 `错题本.md`，建议单独放到私有仓库保存。
