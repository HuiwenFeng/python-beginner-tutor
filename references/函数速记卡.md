# Python 新手函数速记卡

## 记忆总口诀：函数 = 榨汁机
水果放进去（括号里的参数）→ 按开关（用 `()` 调用）→ 流出果汁（结果）。
记任何函数只记三件事：**叫什么、括号里放什么、返回什么**。

## 新手必背 8 个
| 函数 | 中文记法 | 例子 | 结果 |
|------|----------|------|------|
| `print()` | 打印给你**看** | `print("hi")` | 显示 `hi` |
| `input()` | 问你要**输入** | `name = input("你叫什么")` | 返回输入的文字 |
| `len()` | 长度 | `len("abc")` | `3` |
| `type()` | 看看你**是什么类型** | `type(3)` | `<class 'int'>` |
| `int()` | 变**整数** | `int("5")` | `5` |
| `float()` | 变**小数** | `float("3.5")` | `3.5` |
| `str()` | 变**字符串** | `str(100)` | `"100"` |
| `range()` | 一串**范围** | `range(5)` | `0,1,2,3,4`（不含 5）|

> 联想：`len`=**length**（长度）、`int`=**integer**（整数）、`str`=**string**（字符串）、`float`=**浮动**的小数点。

## 字符串常用“方法”（点 . 开头）
| 方法 | 中文记法 | 例子 | 结果 |
|------|----------|------|------|
| `.upper()` | 变大写 | `"abc".upper()` | `"ABC"` |
| `.lower()` | 变小写 | `"ABC".lower()` | `"abc"` |
| `.strip()` | 撕掉两边空白 | `"  hi  ".strip()` | `"hi"` |
| `.replace()` | 替换 | `"a,b".replace(",", "-")` | `"a-b"` |
| `.split()` | 切开 | `"a,b".split(",")` | `["a", "b"]` |
| `.find()` | 找位置 | `"abc".find("b")` | `1` |

> 联想：`upper` 向上（大写）、`lower` 向下（小写）、`strip` 撕纸条、`replace` 换一个、`split` 劈开、`find` 找。

## 最容易混的一个坑
- `print("hi")` → 调用函数，**打印**出 `hi`
- `print = "hi"` → 把 `"hi"` **存进**叫 `print` 的变量，不打印
