# 新手常见错误速查

按“症状 → 原因 → 改法”排查，优先看报错的最后一行。

## 1. 没输出（程序跑完但什么都不打印）
- 常见原因：把 `print` 当变量赋值了，如 `print = "hi"`。
- 改法：用括号调用 `print("hi")`。
- 关键：函数名后面必须跟 `()` 才是“让它干活”。

## 2. 语法错误 SyntaxError
- 少了右括号或引号：`print("hi"` 或 `print("hi)`
- 中英文标点混用：用了中文引号“ ”、中文冒号：、中文逗号，
- 改法：统一用英文标点。

## 3. 名字错误 NameError
- 用了没定义的变量，常见是拼写错：`pritn("hi")`、`name` 写成 `nmae`。
- 改法：对照拼写，保持一致。

## 4. 类型错误 TypeError
- 数字和字符串直接相加：`"我" + 18`
- `input()` 返回的是字符串，运算前要转：`int(input("输入数字"))`
- 改法：先 `int()` 或 `str()` 统一类型。

## 5. 缩进错误 IndentationError
- `if`、`for`、`def` 后面那行没缩进，或缩进忽多忽少。
- 改法：同一代码块用相同数量的空格（推荐 4 个空格）。

## 6. 结果不对但不是报错
- `=` 赋值 和 `==` 比较写混：`if a = 1:` 应该用 `if a == 1:`
- `range(5)` 是 0 到 4，不含 5（左闭右开）。

## 排查口诀
- 先看报错**最后一行**（错误类型）→ 再看提示的第几行 → 对照上面类型。
- 没报错却不对 → 多半是赋值/调用、`=` vs `==`、类型问题。
